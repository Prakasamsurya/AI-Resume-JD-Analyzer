# AI Resume & Job Description Analyzer

An AI-powered resume analysis platform that compares a candidate's resume with a target job description, identifies genuine strengths and gaps, provides personalized improvement recommendations, and generates an optimized resume.

## Overview

This application helps candidates understand how well their resume matches a specific job before applying.

The system analyzes the candidate's actual resume evidence against the requirements in a job description and produces:

- Resume-to-JD requirement matching
- Strong, weak, and missing requirement analysis
- Resume improvement recommendations
- Relevant project identification
- Skills to prepare
- Interview questions
- Personalized action plan
- Optimized resume

The system is designed to work with different resumes and job descriptions rather than relying on fixed role-specific logic.
